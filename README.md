# Mon App React

Application React moderne créée avec Vite pour générer une micro-page personnelle.

## Description

Ce projet permet de créer une page de présentation dynamique avec :

- Profil utilisateur (nom, bio, avatar)
- Liens personnalisés
- Icônes de réseaux sociaux avec validation par plateforme
- Prévisualisation mobile en temps réel
- Thèmes visuels et options de typographie

## Fonctionnalités clés

- Gestion complète des liens sociaux
- Validation spécifique des URLs par plateforme
- Affichage uniquement des icônes valides dans la prévisualisation
- Stockage automatique des données dans `localStorage`
- UI construite avec React et Tailwind CSS



## Technologie

- React 19
- Vite
- Tailwind CSS v4
- ESLint
